Netflix Data Visualization using Python

This project focuses on exploring and visualizing the Netflix dataset using **Python, Pandas, and Matplotlib**. The dataset was first cleaned by handling missing values, removing duplicates, and correcting data types to ensure accurate analysis. After preprocessing, different visualizations were created to uncover meaningful insights from the data.

The project includes charts showing the distribution of Movies and TV Shows, content ratings, release year trends, top producing countries, genre distribution, and content duration. These visualizations make it easier to identify patterns, compare categories, and understand how Netflix's content library has evolved over time.

Through this project, I strengthened my skills in **data cleaning, exploratory data analysis (EDA), data visualization, Pandas, and Matplotlib** while learning how to transform raw data into clear, informative visual insights.
